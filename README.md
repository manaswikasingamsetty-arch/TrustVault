# TrustVault – Secure Document Management System

## The Problem

TrustVault aims to provide a simple way to manage documents through a web application. Without proper document management, users may find it difficult to upload, organize, and access their files. This project provides a basic platform for document uploads and document management.

## What I Built

TrustVault is a web application developed using Django and Python. It includes user registration and login pages, a dashboard, and document upload functionality.

The application is designed to provide a simple, user-friendly interface for managing documents. Uploaded documents can be handled through the application's document management features.

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## Features

- User Registration and Login
- User Dashboard
- Document Upload
- Support for PDF, JPG, JPEG, and PNG files
- File size limit of 5 MB
- Simple and User-Friendly Interface

## How to Run It

### Requirements

- Python
- pip
- Git (optional)

### Installation Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/manaswikasingamsetty-arch/TrustVault.git
   ```

2. Open the project folder:

   ```bash
   cd TrustVault
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Apply database migrations:

   ```bash
   python manage.py migrate
   ```

5. Start the development server:

   ```bash
   python manage.py runserver
   ```

6. Open the application in your browser:

   http://127.0.0.1:8000/
